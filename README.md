# AquaAware — Water Conservation Website

AquaAware is a multi-page website created using **HTML, CSS and JavaScript**. It focuses on water conservation, sustainable water use and environmental awareness.

## Features
- Responsive multi-page website
- Home, About, Gallery, Infrastructure, Calculator, Donate and Contact pages
- Water Footprint Calculator
- JavaScript form validation and interaction
- GitHub-ready relative paths
- No backend required

## Technologies
HTML5 • CSS3 • JavaScript

## Water Footprint Calculator
The calculator follows the supplied project model:
- Shower = minutes × 9 L
- Toilet = flushes × 6 L
- Laundry = weekly loads ÷ 7 × 70 L
- Drinking water = entered litres/day

This is an educational estimate, not a scientific measurement of total personal water footprint.

## Run locally
Open `index.html` in a browser.

## GitHub Pages
After pushing the repository, use **Settings → Pages → Deploy from a branch → main → /root**.

## Important
The original code contained computer-specific `C:\Users\...` and `file:///...` paths. This version uses portable relative paths so it can be hosted on GitHub.

## Source basis
This repository was organized from the supplied AquaAware website code and preserves its main water-conservation concept and calculator behavior.
