# Project Notes

This repository was organized from the supplied AquaAware website code.

The original project included water-conservation awareness content, vision,
mission, core values, gallery/infrastructure sections, a water footprint
calculator, donation/support content and a contact form.

The original source contained computer-specific Windows paths such as
`C:\Users\...` and `file:///E:/...`. These cannot work for other computers
or GitHub Pages, so this repository uses portable relative paths.

Original external image/video assets were not copied automatically. Add
owned/licensed assets to `images/` and `videos/` if you want to restore them.
